# macOS Installation Guide for Wune

**English** / [日本語](INSTALL_MACOS.md)

Installation and initial setup instructions for Wune, an LED audio spectrum analyzer inspired by 1980s and 1990s compact stereo systems, on macOS.

## System Requirements

- **Supported Architecture**: **Apple Silicon (`arm64`: M1/M2/M3/M4, etc.) only**
  - *Note*: Intel Mac (`x86_64`) is not supported as no test hardware is available.
- **Hardware-Verified OS**: **macOS 27** (tested and verified on physical Apple Silicon hardware)
  - In theory, Wune is compatible with macOS 14.2 (Sonoma) or later where the Core Audio Process Tap API is available; however, physical hardware verification and testing are performed exclusively on the latest macOS 27.
  - macOS 14.1 and earlier are unsupported because the necessary Core Audio API does not exist.
- Audio output device capable of stereo playback (built-in speakers, headphones, external audio interface, etc.)

## Download and Installation

1. Download the ZIP package from **[GitHub Releases](https://github.com/yshdsnd/wune/releases)**:
   - Package name: **Wune-vX.Y.Z-macos-arm64.zip** (where X.Y.Z is the version number)
   - *Note*: Do not download the "Source code" archive automatically generated by GitHub; use the prebuilt binary ZIP package.
2. Double-click the downloaded ZIP file to extract it.
3. Drag and drop the extracted **`Wune.app`** into your **Applications** folder (`/Applications`), or any folder of your choice.

### Important Notes
- **No Python installation or external dependencies are required.** Wune runs as a self-contained standalone application.

## First Launch and Gatekeeper (Security Prompts)

Because this distribution is an open-source build signed with an ad-hoc certificate, macOS Gatekeeper blocks the application on first launch with an alert: **"“Wune” was not opened (Apple could not verify that it is free of malware)"**.

### Authorizing on First Launch (System Settings)
1. Double-click `Wune.app`.
2. When the alert **"“Wune” was not opened"** appears, click **"Done"** to dismiss it (do not select "Move to Trash").
3. Open macOS **System Settings** → **Privacy & Security**.
4. Scroll down to the **Security** section. You will see the notice: **"“Wune” was blocked to protect your Mac."**
5. Click the **"Open Anyway"** button next to it.
6. Authenticate using Touch ID or your Mac's administrator password.
7. The system audio recording permission prompt will then appear; click **"Allow"** (see below).
8. Once authorized, Wune is remembered as safe and can subsequently be opened normally via double-click, Dock, or Launchpad.

> [!TIP]
> **Quick Terminal alternative (recommended)**:
> After placing the app, open Terminal and remove the quarantine attribute with the following command to allow opening immediately without going through System Settings:
> ```bash
> xattr -d com.apple.quarantine /Applications/Wune.app
> ```

## System Audio Recording Permission (First Launch Only)

To visualize playback in real time, Wune captures system audio output using Core Audio's Process Tap API.

1. When first launched, macOS presents a permission dialog: **"Wune would like to record this computer's audio"** (or "Screen & System Audio Recording").
2. Click **"Allow"** (or toggle permission on in System Settings).
3. Once granted, the spectrum display responds in real time to any music played in Music, Spotify, browsers, or other apps.

> [!NOTE]
> - This permission is used strictly to capture system output playback for visualization. Wune does not record microphones, capture your screen, or transmit any audio data.
> - If permission was accidentally denied, open **System Settings** → **Privacy & Security** → **System Audio Recording** (or Screen & System Audio Recording) and enable **Wune**.

## Audio Capture Notes

- Wune captures audio directly from your default macOS output device (built-in speakers, headphones, etc.) at startup.
- Wune does not produce sound itself or alter your output device settings.
- The information bar (toggle with `I`) shows the active device name, sample rate, and channel count.
- If you change your default output device, restart Wune.
- Capture targets stereo channels (channels 0 and 1).

## Controls and Mac Shortcuts

Click the main window to focus it before pressing keyboard shortcuts:

| Action | Function |
| --- | --- |
| F2 (or Fn + F2) | Open Settings |
| F11 (or Fn + F11) | Toggle fullscreen / windowed mode |
| Space | Pause / resume display; playback continues |
| T, or click theme name at top right | Switch to next color theme |
| I | Show / hide information bar |
| Esc, Q, or Cmd + Q | Quit |
| Drag window border | Resize display |

*Note*: If "Use F1, F2, etc. keys as standard function keys" is disabled in macOS Keyboard Settings, hold the **Fn key** while pressing function keys (e.g., `Fn + F2`).

## Updating and Uninstalling

### Updating
1. Quit the running Wune application (`Cmd + Q` or `Q` / `Esc`).
2. Extract the new ZIP archive and replace the existing `Wune.app`.
3. Your settings are preserved in the user Library directory and will carry over automatically.

### Uninstalling
1. Quit Wune.
2. Move `Wune.app` to the Trash.
3. To delete settings and log files completely, remove the folder described below.

## Configuration Location and Reset

Settings and logs are stored in:

```text
~/Library/Application Support/Wune
```

| File | Description |
| --- | --- |
| `settings.json` | Visual preferences, custom themes, window position, and size |
| `Wune.log` | Application startup and runtime log (overwritten each launch) |

### Resetting Settings
Quit Wune, then move or delete `settings.json` before restarting. Wune will launch with factory default settings.

## Troubleshooting

| Symptom | What to Check |
| --- | --- |
| Blocked by security prompt | Control-click `Wune.app` and choose Open, or run `xattr -d com.apple.quarantine` in Terminal. |
| Spectrum does not react | Check that audio permission is allowed under System Settings → Privacy & Security. Press Space to verify display is not paused. |
| Stopped after switching output | Restart Wune after changing macOS output devices. |
| F2 does not open Settings | Click the window first. If using a Mac keyboard without standard function keys, press `Fn + F2`. |
| Settings revert or are not saved | Ensure you clicked **Save** in Settings, or clicked **Apply** followed by closing the app normally. |

For unresolved problems or feature suggestions, please visit **[GitHub Issues](https://github.com/yshdsnd/wune/issues)**.
