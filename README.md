WuneWune - 80-90年代風 オーディオスペクトラムアナライザ

# はじめに

80年代、90年代のミニコンポに付いていたスペアナをイメージしたアプリです。

現状は対応OSはWindowsのみ。Windowsで一通り完成したらMacOSやLinux/FreeBSDでも動作するようにする予定です。

オーディオデバイスから読み取ってスペアナが動く状態にはなっています。
表示の配置・LED・配色・動きは設定ウィンドウで変更できます。動作は引き続き調整中です。

## 起動と開発用設定

Python 3.10以降の環境で依存ライブラリをインストールして起動します。

```sh
python -m pip install -r requirements.txt
python main.py
```

組み込みの既定値は `wune/config.py` の `Config` にまとめています。
保存済みのユーザー設定がある場合は、そちらを優先します。

- 音声取得: Windowsの既定の出力デバイスからWASAPIループバック
- サンプルレート: `sample_rate = None`（起動時に出力先から自動取得）
- 読み取り／FFTサイズ: `block_size = 4096`
- 表示: ステレオ、64バンド

VB-CABLEのインストールや仮想デバイスへの振り分けは不要です。
通常のスピーカーやヘッドホンで音楽を再生したまま起動してください。
SoundCardを使い、共有モードで再生中の出力を読み取ります。
Wune自身は音声の再生や、Windowsの既定の出力先の変更を行いません。

`output_device = None` は起動時の既定の出力デバイスを選びます。
別の出力先を指定する場合は、次の一覧のIDまたは名前を `output_device` に設定します。
確実に同じデバイスを選ぶにはIDを使用してください。

```sh
python -c "from wune.soundcard_compat import prepare_soundcard; prepare_soundcard(); import soundcard as sc; [print(s.id, s.name) for s in sc.all_speakers()]"
```

音楽アプリも選択した出力先で再生する必要があります。起動中の出力先変更には
自動追従しないため、変更後はWuneを再起動してください。
ステレオ出力のチャンネル0/1を取得します。サラウンド全体のダウンミックスや
モノラル専用デバイスには対応していません。モノラル表示時も音声取得は2チャンネルです。
接続失敗時はエラーを表示し、マイクや疑似音声には切り替えません。

操作: ESC / Qで終了、F11で全画面切替、Spaceで一時停止、Iで情報欄の表示切替、F2で表示設定。
以前のLキーは表示上の仮フラグだけで実入力を切り替えていなかったため削除しました。
情報欄のfloat32はアプリへ渡されるサンプル形式で、機器のビット深度ではありません。

## 表示設定とライブプレビュー（F2）

メインウィンドウで **F2** を押すと、別ウィンドウに表示設定を開きます。
全画面の場合は通常ウィンドウに戻ります。音声取得とスペクトラム表示は継続します。
Python標準のTkinterを使用します（通常のWindows版Pythonに付属）。

- **配置・LED**：周波数とレベルの向き、L/Rの上下・左右配置、フラット／立体、長方形／角丸／楕円、LEDの縦横比（幅÷高さ、0.25～8）、情報欄の表示・位置。
- **動作**：立ち上がり時間・下降時間・ピーク保持時間・ピーク落下速度。スライダーと数値入力でリアルタイム調整できます。
- **テーマ・配色**：組み込み／ユーザーテーマの選択、新規作成、複製、名前変更、削除。
- 色の用途を一覧で選び、**カラーピッカー**または `#RRGGBB` の入力＋**色を反映**で変更します。点灯／消灯LED、背景、ピーク、目盛り、文字などすべてのテーマ色を編集できます。

色を確定すると、再生中のメイン表示へ即座に反映します。カラーピッカーや名前入力を
開いている間もスペクトラムは動き続けます。形や比率もプレビューでき、必要に応じて
メインウィンドウの寸法を補正します。音声デバイスの再接続や解析値・ピークのリセットは行いません。

組み込みのCLASSIC／BLUE／AMBER／CLASSIC BOXは変更・削除しません。
組み込みテーマの配色・LED形式・形・比率を編集すると、`CLASSIC copy` などの
ユーザー用コピーを自動作成します。新規作成はCLASSICを基にし、複製は選択中のテーマを基にします。
名前は1～40文字で、日本語も使えます。配置や表示方向はテーマとは別の表示設定です。

| ボタン | 動作 |
| --- | --- |
| 保存 | 現在のプレビューとユーザーテーマを直ちにファイルへ保存し、設定ウィンドウを閉じます。次回も同じ表示で起動します。 |
| 適用 | 現在のプレビューを確定して、設定ウィンドウを開いたままにします。ファイルには正常終了時に保存します。 |
| キャンセル／閉じる／Esc | 最後に適用した見た目とテーマ一覧に戻します。まだ適用していなければ設定ウィンドウを開く前に戻します。 |
| 表示を既定に戻す | 配置・LED・配色をCLASSICの既定値へ戻してプレビューします。動き・ユーザーテーマ一覧・バンド数・ウィンドウ位置は保持します。保存／適用前なら取り消せます。 |

設定ウィンドウを開いたままWune本体を終了した場合も、未適用のプレビューを取り消してから保存します。
編集中はメイン側のTキー・バッジ・Iキーによる見た目の変更を止め、設定ウィンドウの操作に統一します。
保存に失敗すると画面を閉じずに理由を表示し、再試行またはキャンセルできます。
全設定・ユーザーテーマ・位置も初期化する場合は、下記の `--reset-settings` を使って起動してください。
バンド数・音声デバイス設定はこの画面には含みません。

## 設定とウインドウ位置の保存

正常終了（閉じるボタン、ESC、Q）時に、ユーザーごとの
`%LOCALAPPDATA%\Wune\settings.json` へ設定を保存します。次回起動時に読み込みます。

Microsoft Store版Pythonでは、Windowsによって実ファイルが次の場所へ転送される場合があります。
PowerShellから通常のLocal\Wuneが見つからない場合はこちらを確認してください。

```text
%LOCALAPPDATA%\Packages\PythonSoftwareFoundation.Python.3.13_qbz5n2kfra8p0\LocalCache\Local\Wune\settings.json
```

`Python.3.13` の部分は使用中のPythonに応じて変わります。設定画面にはPythonから使う論理パスを表示します。

- 通常ウインドウの幅・高さ・位置。全画面中に終了しても、全画面にする直前の位置・サイズを保存します。
- 選択中のプリセット、LED形式・形・縦横比、表示方向、L/R配置、バンド数・チャンネル数、情報欄の表示・位置。
- 起動時には現在のモニターの作業領域と照合します。モニターを外した場合や画面外の位置は、表示できる位置へ戻します。画面より最小レイアウトが大きい場合も、タイトルバーへアクセスできる位置を確保します。

設定は「組み込み既定値 → 保存済みユーザー設定 → 実行中の状態」の順に適用します。
ソースの `CFG` は未保存項目の初期値として引き続き使用できますが、既に保存された項目は上書きしません。
名前付きプリセットを指定すると、そのプリセットの配色・LED形式・形・比率を適用します。
個別の形や比率を指定する場合は `initial_preset: null` にします。
ユーザーテーマは同じJSONの `user_themes` に配色・LED形式・形・比率を保存します。
動きの4項目も `appearance` 内に保存します。テーマを切り替えても動きの設定は保持します。

保存形式はバージョン付きJSONです。既存のversion 1ファイルも読み込めます。手動で編集する場合はアプリを終了してください。
例えば次のような形式で、`appearance` の各項目名は `Config` と対応します。

```json
{
  "version": 1,
  "window": {"width": 916, "height": 504, "x": 100, "y": 100},
  "appearance": {
    "initial_preset": "BLUE",
    "spectrum_orientation": "frequency_vertical",
    "channel_layout": "horizontal",
    "bars": 32
  }
}
```

既定値へ戻すには次のコマンドで起動します。保存ファイルを削除し、ソース末尾の独自 `CFG` 指定も
その起動では使用せず、`Config()` の組み込み既定値から始めます。終了時には現在の設定を改めて保存します。

```powershell
python main.py --reset-settings
```

不正な項目は無視します。JSON自体が壊れている場合や未対応のバージョンの場合は警告を表示し、
ファイルを上書きせずに初期値で起動します。修復するか上のリセットを使用してください。
保存時は一時ファイルを置き換える方式を使い、保存に失敗した場合は警告を表示します。
音声デバイス等の実行エラーで終了した場合は設定を更新しません。

## 20 kHz目盛りと表示上限

表示範囲が20 kHzを含む場合、横軸・縦軸のどちらでも **20kHz** の目盛りを表示します。
96 kHz出力で上限40 kHzの表示でも、可聴帯域の目安として確認できます。
狭い画面では20 kHzを優先し、重なる他の目盛り（端のラベルを含む）は省略します。
周波数目盛り自体を非表示にした場合は表示しません。

F2 → **配置・LED** → **表示上限を20 kHzに制限**で、ハイレゾ出力でも
20 Hz～20 kHzにバンドを割り当てられます。既定はオフで、従来の自動範囲を維持します。

- オン：表示／解析の上限を20 kHzに制限します。
- オフ：48 kHz以下の取得では20 kHz、それを超える場合は最大40 kHzへ戻します。
- どちらも設定済みの上限とナイキスト周波数の安全限界を超えません。
- 出力デバイスの設定、取得レート・形式・ブロックサイズは変更しません。

切替はプレビューに即反映し、保存・再起動時の復元・キャンセルに対応します。
バンドが表す周波数が変わるため、範囲変更時だけバーとピークの履歴をクリアします。
音声接続は維持し、次の入力から新しい範囲で表示します。一時停止中は再開までゼロ表示になります。
「表示を既定に戻す」では制限をオフに戻します。設定ファイル上の項目は
`appearance.limit_to_20khz`（true / false）です。

## レベル表示の基準

帯域ごとのFFTパワーを合計し、Hann窓とFFTサイズを補正してdBへ変換します。
ピーク振幅1.0の正弦波を0 dBの基準とし、`db_min`～`db_max`（既定は−66～0 dB）を
ゲージの0～1へ対応させます。フレームごとの最大値や音量履歴による自動正規化は行いません。
従来の高域強調・パーセンタイル正規化・上限を下げる圧縮を廃止しました。
旧設定の `agc_decay`、`norm_lo_pct`、`norm_hi_pct`、`min_norm_span_db10`、
`compression_knee`、`compression_gamma` は削除しています。

例えば1 kHz正弦波のピーク振幅を−20、−12、−6、−3、−0.1 dBFSとすると、
定常状態の該当帯域はほぼそのレベルになります。ただし帯域境界でエネルギーが分かれると、
最大の帯域も約3 dB低くなり得ます。音楽ではエネルギーが複数帯域に分かれるため、
波形全体のピーク値と各バーは一致しません。音圧（SPL）やトゥルーピークの計測器ではありません。
Windowsや再生アプリ側の音量が取得信号に反映されれば、表示もそれに応じて下がります。

## ビートへの反応とピーク表示

F2 → **動作**タブで、音楽を再生しながら調整できます。

| 設定 | 範囲 | 既定値 | 効果 |
| --- | --- | --- | --- |
| 立ち上がり時間 | 1～1000 ms | 5 ms | 小さいほどビートに素早く反応 |
| 下降時間 | 1～5000 ms | 120 ms | 大きいほどバーの余韻が長い |
| ピーク保持時間 | 0～5000 ms | 120 ms | ピーク線を留める時間 |
| ピーク落下速度 | 0～20 表示全幅/秒 | 2.5 | 大きいほど速く落下。0は落下停止 |

スライダーは即時反映、数値入力はEnterまたは入力欄から移動して反映します。
保存・適用ボタンでも入力中の数値を検証して反映します。無効値は保存できません。
**動きだけ既定に戻す**は配色や配置を変えずに4項目を初期値へ戻します。

保存／適用／キャンセルは外観設定と共通です。キャンセルで設定値は戻りますが、
過去の音声や表示フレームは巻き戻しません。調整時にバー・ピークの現在位置や
保持中の残り時間はリセットしません。保持時間の変更は次のピークから使い、
落下速度は次の描画から、立ち上がり／下降時間は次の音声更新から反映します。
一時停止中は表示状態を保ち、再開後に変更後の動きになります。
動きはテーマに含めず、テーマを切り替えても同じ調整値を使います。


レベル校正後の値に、時間基準のアタック／リリースを1回だけ適用します。
`vis_attack_ms=5`、`vis_release_ms=120` が既定です。指数応答の時定数なので、
立ち上がりは約12 msで目標の90%、下降は約276 msで元の10%になります。
この時間は入力更新が十分速い場合の値で、取得済みの入力へ適用する動きの基準です。
4096サンプルの取得は48 kHzで約85 msかかるため、実際の反応は音声取得間隔にも制限されます。
短いピークは定常正弦波より低く表示される場合があります。取得サイズやFFT処理は変更していません。

ピークは `peak_hold_ms=120` の間保持し、その後 `peak_fall_per_second=2.5`
（1秒あたり表示全幅の2.5倍）の速度で下がります。フレーム数ではなく経過秒数を使い、
一時停止中はピークも停止します。無音でも同じリリースを適用して内部状態を減衰させます。

旧 `smoothing`、`silence_decay`、`post_floor`、`peak_hold_frames`、
`peak_fall_per_frame` と `AudioSpectrum` の `smooth` 引数は廃止しました。
`output_floor` は表示用の極小値カットで、内部のエンベロープ状態には影響しません。

## 配置とウインドウサイズ

ウインドウをリサイズすると、各チャンネルのゲージ幅・高さと目盛りの配置が追従します。
LEDと間隔を含むゲージ全体を、同じ倍率で拡大縮小します。
縦横の隙間はLEDの高さの約1/4に揃え、密集した配置を維持します。
通常ウインドウは、表示方向・L/R配置によらずゲージと目盛りに必要な寸法へ補正します。
片方の寸法が限界なら、余白だけが増える拡大を制限します。全体を大きくするには
ウインドウの角を斜めにドラッグしてください。目盛りもゲージの位置・長さに追従します。
全画面では画面サイズを維持し、L/Rをひとまとまりで中央に配置します。
チャンネル間の余白だけが広がることはありません。
LEDの高さを整数ピクセルで決め、幅と間隔をその高さから丸めるため、
サイズは段階的に変わります。縦横比やバンド数は拡大縮小しても変わりません。
角丸・光沢・縁取りも共通の原画から拡大縮小します。
バンド数・LED段数やピーク状態はリサイズでは変えません。
表示を保てる最小サイズを下回る場合は、そのサイズまで戻します。
F11で全画面から戻ると、直前のウインドウサイズを復元します。

配置はF2の表示設定で変更できます。バンド数などをソースで指定する場合は、
`wune/config.py` 末尾の `CFG` を変更して再起動します（保存済みの同名項目が優先されます）。

```python
# L/Rを上下に配置、各64バンド（既定）
CFG = Config(channel_layout="vertical", bars=64, width=1280, height=800)

# L/Rを左右に配置、各32バンド
CFG = Config(channel_layout="horizontal", bars=32, width=960, height=480)
```

`width` と `height` は起動時のサイズです。各チャンネルに周波数・dB目盛りを表示します。
狭い幅では重なる途中の周波数ラベルを間引き、情報欄の長い文字列を省略します。
周波数範囲や音声処理は配置を変えても共通です。

### 周波数とレベルの向き

`spectrum_orientation="frequency_horizontal"` が従来の表示（横に周波数、縦にレベル）です。
`"frequency_vertical"` にすると、周波数が下から上へ増え、各帯域のレベルが左から右へ伸びます。
文字やLEDの形は回転しません。周波数目盛りは左側、dB目盛りは下側に表示します。
これはL/Rの並べ方を指定する `channel_layout` とは独立した設定です。

起動時の指定サイズや設定変更後の寸法にも、上記のサイズ補正を適用します。

```python
CFG = Config(
    spectrum_orientation="frequency_vertical",
    channel_layout="horizontal",
    bars=32,
    width=960,
    height=800,
)
```

保存して再起動すると反映されます。両方の向きで上下／左右のL/R配置とリサイズに対応し、
バンド数・LED比率・向きに応じて最小サイズを確保します。縦に64バンドを上下2段で並べる場合は
必要な高さが増えるため、32バンドやL/R左右配置も選べます。解析・レベル校正・動きは共通です。

## 配色とゲージの見た目

LEDの形は `led_shape`（`"rectangle"` / `"rounded"` / `"ellipse"`）、
幅÷高さは `led_aspect_ratio` で指定します。1.0なら正方形／円、2.0なら横長です。
これは形の設定で、全体の拡大率ではありません。2.0から2.8への変更は
1.4倍の拡大ではなく、より横長の形への変更です。幅に制約があれば高さが小さくなります。
全体の大きさはウインドウのリサイズで調整します。独立した倍率設定はありません。
最小サイズ付近では整数ピクセルへの丸めによる差が生じます。
最小ウインドウサイズもLEDの縦横比に合わせて計算します。
従来の `bar_gap` / `led_gap` は配置に使用せず、LEDと一緒に間隔を決めます。
CLASSIC・AMBERは角丸、BLUE・CLASSIC BOXは長方形で、いずれも縦横比2.0です。
プリセット切替では形と縦横比も切り替わります。独自設定には `initial_preset=None` を指定します。

```python
CFG = Config(initial_preset=None, led_shape="ellipse", led_aspect_ratio=2.0)
```

`gauge_style="box"` の立体的な縁は長方形に適用します。
角丸の半径はLEDサイズに比例して決まるため、旧 `corner_radius` 設定は廃止しました。

右上のプリセット名バッジを**左クリック**、または**Tキー**で、音声を再生したまま
見た目を切り替えられます。配色とゲージ形式を一緒に切り替え、現在のレベルや
ピーク保持・落下、一時停止状態、音声取得は維持します。

| 順序 | 名前 | 配色・ゲージ |
| --- | --- | --- |
| 1 | CLASSIC | 従来の緑・黄・赤、flat（既定） |
| 2 | BLUE | 青・紫・ピンク、box |
| 3 | AMBER | アンバー系、flat |
| 4 | CLASSIC BOX | CLASSICの配色、box |

組み込みの後にユーザーテーマを順に表示し、最後の次はCLASSICに戻ります。
バッジを非表示にしてもTキーは使えます。起動時の選択はF2の設定画面で保存できます。
Tキーやバッジで切り替えた選択も正常終了時に保存し、次回起動時に復元します。
プリセットの定義は`wune/presets.py`です。

独自の配色を直接指定する場合は、次のように`initial_preset=None`を指定します。
バッジにはCUSTOMと表示し、最初の切り替えでCLASSICになります。
`"box"`はLEDの上・左側にハイライト、下・右側に影を描きます。

```python
CFG = Config(
    initial_preset=None,
    gauge_style="box",
    led_shape="rectangle",
    theme=Theme(
        background=(18, 24, 38),
        green_on=(70, 190, 255),
        yellow_on=(170, 130, 255),
        red_on=(255, 110, 170),
        green_off=(10, 30, 45),
        yellow_off=(25, 18, 40),
        red_off=(40, 15, 25),
        peak=(255, 220, 130),
    ),
)
```

色はRGBの各0〜255で指定します。`Theme`には背景・枠、点灯／消灯LED、
ピーク、目盛り、文字、情報欄、バッジ、一時停止表示の色をまとめています。
`green/yellow/red`は下部・中部・上部の色領域名で、任意の色を指定できます。
従来は消灯色が描画側で固定されていましたが、現在は`*_off`の設定が反映されます。
既定値は従来実際に描画されていた色を維持しています。
背景には既存の残像用オーバーレイが重なるため、描画後の色は指定値より暗くなります。
立体感はLEDが大きいほど分かりやすく、幅または高さが3px未満では単色表示にします。
スタイルは同じLED矩形に描画するため、解析値・ピーク保持／落下の計算は共通です。

## 整理時に維持した計算

表示・解析の上限は、取得サンプルレートが48 kHz以下なら20 kHz、
48 kHzを超える場合は40 kHzです（96 kHz取得なら20〜40 kHzも表示）。
`max_freq_hz`でこれより低い上限を指定できます。いずれもナイキスト周波数の
手前に制限され、周波数目盛りと端のラベルにも適用されます。
既定では選択した出力先のWindows共有モードのミックスレートを起動時に取得し、
録音・FFT・情報欄に同じレートを使用します。音源ファイルのレートやDACの内部動作を
検出するものではなく、96 kHz設定でも音源に超音波成分があるとは限りません。
Windows側の出力レートを変更した後はWuneを再起動してください。
固定レートで検証する場合は`sample_rate = 48_000`などを指定できます。
自動取得に失敗した場合はエラーで終了し、48 kHzに黙って切り替えません。

Hann窓、FFT、既存の帯域割り当て、高域の重み付け、無音時の減衰、
エンベロープ、ピーク保持と描画の計算は調整していません。
AGC係数0.98、正規化の10/95パーセンタイル、平滑化係数0.7など、
実処理側に埋め込まれていた値を設定の既定値にしています。
未使用だった設定値0.99や20/90には切り替えていません。
色のしきい値は従来どおり `wune/colors.py` の `Theme` が管理します。

Issue #1の48 kHz固定設定は、Issue #6で出力先への自動追従（起動時のみ）に変更しました。
xlevelの挙動の再現は、この変更には含めません。

## 検証

WindowsではSoundCard 0.4.6に固定しています。同版の`PROPVARIANT`領域が
WindowsのBLOB値に対して小さすぎるため、`wune/soundcard_compat.py`で
デバイス情報を取得する前に確保サイズ・ゼロ初期化・解放を補正します。
インストール済みライブラリのファイルは書き換えません。
報告された`0xC0000374`の解消は実機で再確認が必要です。

```sh
python -m unittest discover -s tests -v
```

テストでは実際のNumPyで固定音声を解析し、整理前のコミット
`773c8dd33d857fbd169b029e2538a4efd8dcf1e0` を48 kHz／4096フレームで動かして
採取した値と比較します（モノラル入力の複製、ステレオ、低音量、無音）。
音声・アプリ制御のテストではpygameとSoundCardの代替を使います。
テーマのテストは実際のpygameで画面を開かずSurfaceへ描画します。
これらは実機の音声経路の確認にはなりません。

Windows実機でのWASAPIループバック動作は別途確認が必要です。
VB-CABLEを使用せず、通常のステレオ出力先で次を確認してください。

1. 音楽がスピーカー／ヘッドホンから聞こえたまま起動し、情報欄に出力先の設定レートと選択した出力名が表示される。
2. 左右のスペクトラムが音声に反応し、再生停止で減衰する。再開後も反応する。
3. Spaceで停止・再開できる（最初の入力前に停止してもエラーにならない）。
4. F11、I、Q／ESCと閉じるボタンが動く。
5. 終了後も通常の再生が継続し、Wuneを再起動できる。
6. `output_device` に別の出力先を指定し、その出力先の音声を取得できる。
