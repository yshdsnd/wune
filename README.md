WuneWune - 80-90年代風 オーディオスペクトラムアナライザ

# はじめに

80年代、90年代のミニコンポに付いていたスペアナをイメージしたアプリです。

現状は対応OSはWindowsのみ。Windowsで一通り完成したらMacOSやLinux/FreeBSDでも動作するようにする予定です。

オーディオデバイスから読み取ってスペアナが動く状態にはなっています。
ただし、設定はテキストベース。動作はまだまだ調整中です。

## 起動と開発用設定

Python 3.10以降の環境で依存ライブラリをインストールして起動します。

```sh
python -m pip install -r requirements.txt
python main.py
```

設定は `wune/config.py` の `Config` にまとめています。

- 入力: `CABLE Output (VB-Audio Virtual Cable), Windows WASAPI`
- サンプルレート: `sample_rate = 48_000`
- 読み取り／FFTサイズ: `block_size = 4096`
- 表示: ステレオ、64バンド

VB-CABLEへ音声を送る側も48 kHzの開発用設定に合わせてください。
デバイス名は `python -m sounddevice` で確認できます。別の入力を使う場合は
`input_device` を変更します。接続失敗時はエラーを表示し、疑似音声には切り替えません。

操作: ESC / Qで終了、F11で全画面切替、Spaceで一時停止、Iで情報欄の表示切替。
以前のLキーは表示上の仮フラグだけで実入力を切り替えていなかったため削除しました。
情報欄のfloat32はアプリへ渡されるサンプル形式で、機器のビット深度ではありません。

## 整理時に維持した計算

Hann窓、FFT、既存の帯域割り当て、高域の重み付け、無音時の減衰、
エンベロープ、ピーク保持と描画の計算は調整していません。
AGC係数0.98、正規化の10/95パーセンタイル、平滑化係数0.7など、
実処理側に埋め込まれていた値を設定の既定値にしています。
未使用だった設定値0.99や20/90には切り替えていません。
色のしきい値は従来どおり `wune/colors.py` の `Theme` が管理します。

起動箇所に残っていた96 kHz指定を除き、Issue #1で指定された48 kHzを使います。
96 kHz対応の拡張やxlevelの挙動の再現は、この整理には含めません。

## 検証

```sh
python -m unittest discover -s tests -v
```

テストでは実際のNumPyで固定音声を解析し、整理前のコミット
`773c8dd33d857fbd169b029e2538a4efd8dcf1e0` を48 kHz／4096フレームで動かして
採取した値と比較します（モノラル入力の複製、ステレオ、低音量、無音）。
pygameとsounddeviceはテスト用の代替を使うため、実機の表示・音声経路の
確認にはなりません。

Windows上ではVB-CABLEへ音声を流して次を確認してください。

1. 起動し、48.0 kHzと選択した入力名が表示される。
2. 左右のスペクトラムが入力に反応し、無音で減衰する。
3. Spaceで停止・再開できる（最初の入力前に停止してもエラーにならない）。
4. F11、I、Q／ESCと閉じるボタンが動く。
5. 終了後に再起動でき、入力ストリームが残らない。
