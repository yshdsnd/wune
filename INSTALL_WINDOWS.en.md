# Windows Installation Guide for Wune

**English** / [日本語](INSTALL_WINDOWS.md)

Installation and initial setup instructions for Wune, an LED audio spectrum analyzer inspired by 1980s and 1990s compact stereo systems, on Windows.

## System Requirements

- **Tested environment**: Windows 11 (64-bit), using the x64 package
- Audio output device capable of stereo playback (speakers, headphones, external DAC, etc.)
- *Note*: Windows 10 and Windows on ARM are untested. No packages are provided for 32-bit Windows.

## Download and Launch

1. Download the Windows ZIP package from **[GitHub Releases](https://github.com/yshdsnd/wune/releases)**.
   - Package name: **Wune-vX.Y.Z-win64.zip** (where X.Y.Z is the version number)
   - *Note*: Do not download the "Source code" archive automatically generated by GitHub; use the prebuilt binary ZIP package.
2. Right-click the downloaded ZIP file and select **Extract All** to extract it to a folder of your choice.
3. Open the extracted **Wune** folder.
4. Play music or audio through your speakers or headphones using your preferred audio player.
5. Double-click **Wune.exe** to launch.

### Important Notes
- **No Python installation or administrator privileges are required for normal use.**
- Do not launch Wune directly from within the ZIP file; always extract the entire folder first.
- The **`_internal`** folder must stay in the same directory as `Wune.exe`. Do not move `Wune.exe` alone. You can create a desktop shortcut to `Wune.exe` if desired.

## Audio Capture Notes

- Wune captures audio output from the default Windows playback device at startup via WASAPI loopback.
- Wune does not produce sound itself or alter your output configuration.
- The information bar (toggle with `I`) displays the active device name, sample rate, and channel count.
- If you switch output devices or change the system sample rate in Windows, restart Wune.
- Capture targets channels 0 and 1. Multichannel surround downmixing and mono-only devices are not supported.

## Updating and Uninstalling

### Updating
1. Close the running Wune instance.
2. Extract the new version's ZIP package into a separate folder, and run the new `Wune.exe`.
3. Because settings are preserved in your user profile folder, your customizations will automatically carry over.
4. After verifying that the new version works properly, delete the old folder and update any shortcuts.

### Uninstalling
1. Close Wune.
2. Delete the extracted application folder and any shortcuts.
3. If you also wish to remove configuration files and logs, delete the user data directory described below.

## Configuration Location and Reset

Settings and diagnostic logs are stored in the following folder. You can paste this path into the Windows File Explorer address bar:

```text
%LOCALAPPDATA%\Wune
```

| File | Description |
| --- | --- |
| `settings.json` | Visual preferences, user color themes, window size, and position |
| `Wune.log` | Startup and runtime log for the packaged application (overwritten each launch) |

The Settings window (`F2`) also displays this path at the bottom. To back up your settings, close Wune and copy `settings.json`.

### Resetting Settings
- **Manual Reset**: Close Wune, then **move or delete `settings.json`** before restarting Wune. User themes and window placement will revert to defaults.
- **Command-line Reset**: Open PowerShell in the folder containing `Wune.exe` and run:
  ```powershell
  .\Wune.exe --reset-settings
  ```
  *(This permanently deletes the settings file; back it up first if needed).*

## Troubleshooting

| Symptom | What to Check |
| --- | --- |
| Does not start or closes immediately | Verify that the entire ZIP was extracted and that `_internal` exists next to `Wune.exe`. Check any displayed error and inspect `Wune.log`. |
| Spectrum does not move | Press `Space` to make sure visualization is not paused. Verify that audio is playing and that the device in the info bar (`I`) matches your music player's output. |
| Stops reacting after switching headphones | Check the default Windows output device and restart Wune. |
| Keyboard shortcuts (F2, etc.) do not respond | Click the main window to give it focus. Verify that the Settings dialog is not open in the background. |
| Settings revert or are not saved | Ensure you clicked **Save** in Settings, or clicked **Apply** followed by closing the app normally. |
| Settings dialog does not change language | After changing the language, save or apply the settings and reopen the dialog with `F2`. |
