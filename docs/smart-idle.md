# スマートアイドル

音声レベルとピークがすべてゼロになり、操作や設定画面の表示がない場合、
30フレーム描画を続けてから描画・画面転送を省略します。
その後も60フレームごとに再描画します（60 FPS設定なら約1秒ごと。
音声取得などによる実際のループ速度に依存します）。

音声取得・解析、イベント取得、設定画面との通信は通常どおり継続します。
音が戻った最初のフレームで描画を再開し、追加の待機時間は入れません。
無音入力のFFT省略は既存の音声処理が担当します。

メニュー・終了確認・設定画面の表示中、一時停止中は通常描画を維持します。
リサイズ、ウィンドウ復帰、露出を含むpygameイベントは再描画の契機です。
設定のプレビューやキャンセルはイベントがなくても再描画を要求するため、
設定プロセスが閉じた直後の巻き戻しも表示されます。

WindowsとmacOSのCIでは、描画間引き中の音声取得継続、音声再開、
ピーク減衰、メニュー・終了確認・設定、一時停止、復帰イベントを検証します。
実機のCPU使用率・消費電力の削減率は計測していません。
